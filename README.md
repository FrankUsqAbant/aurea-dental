## 🦷 Sobre el Proyecto

**Áurea Dental** es un sitio web profesional para una clínica odontológica premium en Madrid. Diseñado para una clientela de economía media-alta, cada detalle — desde la tipografía editorial hasta la paleta de colores crema y dorado — comunica excelencia, confianza y calidez.

> *"The design is exceptionally polished, cohesive, and production-ready. The color palette creates a premium, trustworthy, and calming aesthetic."* — AI Design Review

### 🎨 Diseño

| Elemento | Elección |
|----------|----------|
| **Tipografía** | Playfair Display (headings) + Inter (body) |
| **Paleta** | Crema `#FAF8F4` · Dorado `#C6A962` · Carbón `#1A1A1A` |
| **Inspiración** | Apple — espacios blancos, foco en contenido, un solo acento |
| **Imágenes** | Pixabay — fotos reales de clínica, gratuitas, sin atribución |
| **Responsive** | Mobile-first, menú hamburguesa, animaciones con `prefers-reduced-motion` |

### 📋 Secciones

- **Hero** — Foto real de clínica + SVG diente dorado + CTAs
- **Servicios** — 6 especialidades en grid con hover effects
- **Diferenciadores** — 4 pilares: tecnología, especialistas, atención, garantía
- **Galería** — 3 fotos reales de la clínica
- **Equipo** — 3 doctores con bios profesionales
- **Testimonios** — 4 reseñas 5★
- **Contacto** — Formulario completo con select de servicios
- **Footer** — Navegación, legal, registro sanitario

### 🚀 Despliegue

El sitio es un solo archivo **HTML + CSS vanilla** — sin frameworks, sin dependencias, sin build steps. 

```bash
# Abrir directamente
open index.html

# O servir localmente
python -m http.server 8080
```
